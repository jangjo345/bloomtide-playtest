# BLOOMTIDE

개발 중인 BLOOMTIDE 커플 시승판의 실행용 Web artifact입니다. 소스 코드는 포함하지 않습니다.

- 계정, 분석, 추적 기능이 없습니다.
- 진행은 현재 Safari 브라우저에만 저장됩니다.
- 같은 아이폰과 같은 일반 Safari 탭에서 한 사람이 플레이한 뒤 handoff하여 다음 사람이 이어갑니다.
- 서로 다른 기기 사이의 세계 공유는 지원하지 않습니다.
- Safari 사이트 데이터를 삭제하면 진행도 함께 삭제될 수 있습니다.
- 미완성 개발 빌드이며 현재 cottage, resident, 소품과 지도는 최종 설정이 아닙니다.

실행 주소: https://jangjo345.github.io/bloomtide-playtest/
